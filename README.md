# Веб-мессенджер на FastAPI

Небольшой пет-проект: адаптивный веб-мессенджер с доставкой сообщений в реальном времени и хранением истории, написанный на FastAPI и чистом JS.

Изначально делал проект для отработки навыков системного дизайна, работы с асинхронными БД и протоколом WebSockets в рамках образовательной программы VK.

### Что внутри

* Легковесный бэкенд на FastAPI (фронтенд-шаблон отдается прямо из скрипта для автономного запуска в один клик).
* Адаптивный интерфейс: Tailwind CSS, эффекты Glassmorphism и базовый JS для логики работы чата.
* Секция реального времени: WebSockets с предварительной JWT-авторизацией для мгновенной доставки сообщений без перезагрузки.
* Утилита автозапуска в `main.py`: при старте скрипт сам поднимает сервер на порту 8080 и автоматически открывает новую вкладку с интерфейсом приложения в браузере по умолчанию.

### Особенности архитектуры

Все операции записи и чтения истории сообщений вынесены в изолированные асинхронные сессии (через SQLAlchemy и aiosqlite). Это было сделано намеренно, чтобы избежать глухих блокировок базы данных (`Database is locked`) при одновременной отправке большого количества сообщений от разных пользователей и не ломать логику соединения.
