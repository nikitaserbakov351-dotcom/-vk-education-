Nexus Chat — Web Messenger MVP
Проект разработан в рамках образовательной программы VK. Представляет собой современный веб-мессенджер с личными и групповыми чатами, доставкой сообщений в реальном времени и хранением истории.

Реализованный функционал (MVP)
Аутентификация: Безопасный вход с использованием JWT-токенов.

Обмен сообщениями в реальном времени: Реализовано на базе протокола WebSocket. Мгновенная двунаправленная доставка сообщений без перезагрузки страницы.

Хранение истории: Все сообщения надежно сохраняются в реляционной базе данных (SQLite) с использованием асинхронного драйвера. При входе в чат автоматически подгружается история предыдущей переписки.

Современный UI/UX: Клиентская часть выполнена с использованием Tailwind CSS в стиле Glassmorphism. Реализован стильный адаптивный дизайн, плавная анимация появления сообщений, сохранение сессии в браузере и визуальное разделение сообщений на "свои" и "чужие".

Защита от сбоев: WebSocket-соединения защищены строгой проверкой JWT до момента рукопожатия (защита от спам-подключений), а операции с базой данных асинхронно изолированы для предотвращения блокировок.

Стек технологий
Backend: Python 3, FastAPI, Uvicorn, WebSockets.

База данных: SQLite, SQLAlchemy (Async), aiosqlite.

Безопасность: PyJWT.

Frontend: HTML5, Vanilla JavaScript, Tailwind CSS.

Как запустить проект локально
Склонируйте репозиторий:bash
git clone <ссылка_на_ваш_репозиторий>

Установите необходимые зависимости из файла requirements:

Bash
pip install -r requirements.txt
Запустите главный файл сервера:

Bash
python main.py
Сервер самостоятельно запустится на http://127.0.0.1:8080 и автоматически откроет интерфейс мессенджера в вашем браузере.
